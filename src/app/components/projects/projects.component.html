Frontend architecture and feature engineering for an enterprise CRM platform used by business teams to manage customer workflows, role permissions, and operational records.

My contribution

Built and maintained the Angular frontend end-to-end — architecting configurable UI components, route access guards, and reactive API services — shipping with Jasmine unit tests in an Agile delivery workflow.

Technical Highlights
  • → Reusable Angular component architecture for configurable UI modules
  • → Role-based access control (RBAC) with route guards across features
  • → Lazy-loaded routing and declarative RxJS stream management
  • → REST API integration with typed services and auth interceptors
  • → Comprehensive unit tests with Jasmine harnesses and Karma runner
