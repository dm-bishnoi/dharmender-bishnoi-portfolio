# Project Rules for Codex / Antigravity

This file (`GEMINI.md`) contains project-specific instructions and style rules for your AI assistant. The AI will automatically read these rules when working in this project.

## Tech Stack & Guidelines
- **Framework**: Angular
- **Styling**: Vanilla CSS, Responsive Design
- **Key Principles**: High-quality visual design, clean code, responsive aesthetics.

## AI Assistant Customizations
You can further customize the AI's capabilities by adding files to the `.agents/` folder:
- `.agents/rules/`: Add additional markdown files to define more specific rules.
- `.agents/skills/`: Add custom workflows and instructions that the AI can trigger on demand.
- `.agents/plugins/`: Bundle collections of skills and rules together.
